📖 第一章：核心概念與工具定位

1.1 DeepSeek Harness (dsh) 到底是什麼？

DeepSeek Harness 是 DeepSeek 官方為開發者設計的 自主 Agent（智能代理）開發測試框架。 它的標語是 "Everything is a Plugin"（一切皆插件）。

與傳統的 AI 工具相比，它的定位非常鮮明：

  • 雲端對話 AI（如 ChatGPT / DeepSeek 網頁版）： 被動式問答，只能提供程式碼文字，需要手動複製貼上。 適合問問題、查資料、撰寫文章。
  • 通用雲端 Agent（如 Manus）： 在雲端虛擬機全自動執行任務（搜集資料、寫報告）。 適合完全交由雲端處理的全自動工作，但無法直接存取與修改你本地電腦的專案檔案。
  • 本地寫程式 Agent（DeepSeek Harness）： 綁定你電腦的 VS Code 工作區（Folder），具備 檔案讀寫 與 Terminal 指令執行 權限，直接在你電腦上幫你寫網站、改 Code、安裝套件與除錯。

🔒 第二章：安全性與運作機制拆解

2.1 運作架構（混合分工）

  • 本地端（你的電腦）：
    • 執行 UI 控制介面（網址：http://127.0.0.1:3080）。
    • 讀取/寫入 VS Code 打開的專案資料夾。
    • 在你的許可下，於本地 Terminal 執行編譯或套件安裝指令。
  • 雲端（DeepSeek 大腦 API）：
    • 接收你的自然語言指令與程式碼上下文，進行高階邏輯推理並生成修改方案。

2.2 安全機制與沙盒保護（Sandbox）

  • 工作區邊界（Workspace Restriction）： AI 被嚴格鎖定在你使用 VS Code 開啟的那個資料夾內，絕不可能越界去修改你桌面、下載區或系統硬碟的其他檔案。
  • 審核政策（Approval Policy）： 當 AI 嘗試寫入檔案或跑敏感命令時，網頁介面上會跳出確認提示（Ask Approval），你點擊授權後才會執行。
  • 多檔案連動修改： 你只需提出「最終需求」（例如：「新增登入功能」），AI 會自主掃描資料夾內的所有檔案，判斷 HTML、CSS、JS 各需要修改哪些地方，並一次過自動完成。

🔑 第三章：申請 DeepSeek API Key（圖文級步驟）

  1. 進入官網： 打開瀏覽器前往 https://platform.deepseek.com。
  2. 帳號註冊： 點選 Sign Up，可使用 Google 帳號一鍵登入，或輸入手機號碼/Email 註冊。
  3. 建立金鑰：
    • 登入後點選左側選單 API keys。
    • 點擊 Create new secret key 按鈕。
    • 輸入自訂名稱（如 My-VSCode-DSH），點擊 Create。
  4. 保存 Key：
    • 畫面會彈出一串以 sk- 開頭的字串（如 sk-123456789abcdef...）。
    • 點擊 Copy 並立刻貼到記事本備份（該視窗關閉後將無法再查看完整 Key）。
  5. 確認用量： 點選左側 Usage 或 Top up，新帳號通常享有免費贈送的 Token 額度，額度用完後充值極為便宜（改一次網站約花費幾分錢）。

🛠️ 第四章：新手一步一步安裝與啟動教學

1

在 VS Code 中開啟專案

打開 VS Code 編輯器 ➔ 點擊 File ➔ Open Folder... ➔ 選擇存放網站目標資料夾。

2

啟動背景 AI 服務

點擊 Terminal ➔ New Terminal，輸入以下指令：

Terminal Command npx @deepseek-ai/dsh web

提示安裝打 y，顯示 http://127.0.0.1:3080 即啟動成功。

3

進入 Web UI 並配置

瀏覽器開啟 http://127.0.0.1:3080 ➔ Settings ➔ Models 貼入 API Key，指定 Workspace 資料夾。

4

開始對話與檢視成果

用自然語言下達指令，送出後 AI 自動改寫，切回 VS Code 即可查看程式碼更新！

💡 第五章：進階提問公式與 4 大高效開發策略

5.1 最佳提問公式（Prompt Formula）

下指令時遵循：「背景 + 目標 + 限制」，產出結果最精準。

❌ 反面範例：「幫我改好這個網站。」（太模糊，AI 容易自由發揮改壞東西）
✅ 正面範例：
「【背景】這是一個履歷網站。
【目標】請在頁面底部新增一個 Contact Form 表單，包含 Name、Email 與 Message 輸入框。
【限制】請只修改 index.html 與 style.css，不要改動 assets/ 資料夾內的任何圖片檔案。」

5.2 四大開發策略

  • 增量開發 (Incremental Development)： 切勿一次給予過龐大的需求（如：「幫我做一個 Facebook」）。 應拆解成小步快跑：先做登入框 ➔ 再做黑夜模式 ➔ 再做響應式排版。
  • 明確指定改動檔案： 若只需調整樣式，明確告知：「請只針對 assets/style.css 進行修改。」
  • 善用版本控制備份： 在進行大範圍改動前，先複製一份專案資料夾備份，或執行 git commit，方便改砸時一鍵復原。
  • 日後開發極簡 3 步驟：
    1. VS Code：開啟 Folder ➔ 執行 npx @deepseek-ai/dsh web
    2. 瀏覽器：開啟 http://127.0.0.1:3080 下指令
    3. VS Code：切回查看並測試改好的 Code！

📁 第七章：如何讓 AI（dsh）精準識別不同專案？

如果你的電腦上有多個專案，想要讓 AI 工具（例如 DeepSeek CLI / dsh）明確知道你現在是在討論或修改哪一個專案，最直接且有效的方法有以下 3 個操作層面的做法：

1. 最推薦：將 Terminal 切換到該專案的資料夾再啟動

dsh 啟動時會以你目前 Terminal 所在的資料夾（工作目錄 Working Directory）作為基準。

如果你想處理 Project A：

先在 Terminal 切換到 Project A 的路徑：

Bash Command cd /path/to/your/ProjectA

再執行啟動指令：

Bash Command npx @deepseek-ai/dsh web

這樣工具在讀取專案環境、搜尋區域檔案或執行專案內指令時，就會嚴格鎖定在 Project A。

2. 在 VS Code 中分別打開專案 Terminal

如果你習慣使用 VS Code：

  1. 在 VS Code 打開 Project A 的視窗。
  2. 點擊頂部選單 Terminal -> New Terminal（新終端機）。
  3. 此時終端機預設就會在 Project A 的目錄下，直接輸入：
    Bash Command npx @deepseek-ai/dsh web
  4. 如果要換成 Project B，就在 VS Code 開啟 Project B 的視窗，並重複相同步驟即可。

3. 在 Prompt（提示詞）中明確指定專案名稱或檔案路徑

如果你不想頻繁切換 Terminal，或者同時打開了多個專案，可以直接在對話中加上上下文說明：

  • 明確指定專案名稱：
    「我們現在要處理的是 Project A（例如：my-frontend-app），請幫我檢查這段 code...」
  • 提供具體檔案路徑：
    「請幫我看 ./ProjectA/src/components/Header.jsx 這個檔案...」

🖼️ 第八章：圖像處理能力與替代方案

簡短的回答是：DeepSeek 官方的 API 現階段是「純文字（Text-only）」模型，它無法直接閱讀圖片（Pixels），也無法直接繪製/生成圖片。

但你可以透過「組合拳 / 轉換」的方式，讓它間接幫你處理圖像任務！以下拆解它的運作機制與解決方案：

1. 如果你想「給它看圖片（圖片輸入）」

你不能直接把 PNG / JPG 的圖片或圖片連結（URL）傳給 DeepSeek API。

🛠️ 解決方案：先轉文字（OCR / 描述），再給 DeepSeek

你可以在專案裡加上一個「圖像識別 Adapter」：

  1. 圖片傳給 OCR / Vision 模型：先用免費或專門的視訊 API（例如 Google Vision, GPT-4o, 或本地的 OCR 工具）將圖片中的文字提取出來，或者將圖片內容轉換成文字描述。
  2. 文字傳給 DeepSeek：把你獲得的「文字描述 / 提取出來的文字」餵給 DeepSeek。
  3. DeepSeek 進行邏輯處理：DeepSeek 收到這些文字後，就能幫你分析、除 Bug、重構程式碼，或是翻譯和排版了！

2. 如果你「用文字描繪圖像（圖像詞語）」

如果你是用文字向它描述圖像特徵（例如：「這是一張藍色背景、中間有一個紅色按鈕的 UI 截圖」），DeepSeek 完全可以處理！

  • 它可以做：根據你的文字描述，幫你寫出對應的 HTML / CSS / Tailwind 程式碼來還原那個畫面；或者幫你寫出 Prompt（提示詞），讓你拿去 Midjourney / Stable Diffusion 生成圖片。
  • 它不能做：它無法直接輸出一張 .jpg 或 .png 圖檔（它不是 DALL-E 或 Stable Diffusion 這種生成式畫圖模型）。
