📚 DeepSeek Harness (dsh) 終極開發實戰全書

📖 第一章：核心概念與工具定位

1.1 DeepSeek Harness (dsh) 到底是什麼？

DeepSeek Harness 是 DeepSeek 官方為開發者設計的 自主 Agent（智能代理）開發測試框架。它的標語是 "Everything is a Plugin"（一切皆插件）。

與傳統的 AI 工具相比，它的定位非常鮮明：

  • 雲端對話 AI（如 ChatGPT / DeepSeek 網頁版）：被動式問答，只能提供程式碼文字，需要手動複製貼上。適合問問題、查資料、撰寫文章。
  • 通用雲端 Agent（如 Manus）：在雲端虛擬機全自動執行任務（搜集資料、寫報告）。適合完全交由雲端處理的全自動工作，但無法直接存取與修改你本地電腦的專案檔案。
  • 本地寫程式 Agent（DeepSeek Harness）：綁定你電腦的 VS Code 工作區（Folder），具備 檔案讀寫 與 Terminal 指令執行 權限，直接在你電腦上幫你寫網站、改 Code、安裝套件與除錯。

🔒 第二章：安全性與運作機制拆解

2.1 運作架構（混合分工）

  • 本地端（你的電腦）：
    • 執行 UI 控制介面（網址：http://127.0.0.1:3080）。
    • 讀取/寫入 VS Code 打開的專案資料夾。
    • 在你的許可下，於本地 Terminal 執行編譯或套件安裝指令。
  • 雲端（DeepSeek 大腦 API）：
    • 接收你的自然語言指令與程式碼上下文，進行高階邏輯推理並生成修改方案。

2.2 安全機制與沙盒保護（Sandbox）

  • 工作區邊界（Workspace Restriction）：AI 被嚴格鎖定在你使用 VS Code 開啟的那個資料夾內，絕不可能越界去修改你桌面、下載區或系統硬碟的其他檔案。
  • 審核政策（Approval Policy）：當 AI 嘗試寫入檔案或跑敏感命令時，網頁介面上會跳出確認提示（Ask Approval），你點擊授權後才會執行。
  • 多檔案連動修改：你只需提出「最終需求」（例如：「新增登入功能」），AI 會自主掃描資料夾內的所有檔案，判斷 HTML、CSS、JS 各需要修改哪些地方，並一次過自動完成。

🔑 第三章：申請 DeepSeek API Key（圖文級步驟）

  1. 進入官網：打開瀏覽器前往 https://platform.deepseek.com。
  2. 帳號註冊：點選 Sign Up，可使用 Google 帳號一鍵登入，或輸入手機號碼/Email 註冊。
  3. 建立金鑰：
    • 登入後點選左側選單 API keys。
    • 點擊 Create new secret key 按鈕。
    • 輸入自訂名稱（如 My-VSCode-DSH），點擊 Create。
  4. 保存 Key：
    • 畫面會彈出一串以 sk- 開頭的字串（如 sk-123456789abcdef...）。
    • 點擊 Copy 並獨立貼到記事本備份。
    ⚠️ 特別注意： 該視窗關閉後將無法再查看完整 Key！
  5. 確認用量：點選左側 Usage 或 Top up，新帳號通常享有免費贈送的 Token 額度，額度用完後充值極為便宜（改一次網站約花費幾分錢）。

🛠️ 第四章：新手一步一步安裝與啟動教學

步驟 1：在 VS Code 中開啟專案

  1. 打開 VS Code 編輯器。
  2. 點擊頂部選單 File ➔ Open Folder...（開啟資料夾）。
  3. 選擇你存放網站檔案（如含有 index.html）的目標資料夾。

步驟 2：啟動背景 AI 服務

  1. 點擊頂部選單 Terminal ➔ New Terminal（新建終端機）。
  2. 在視窗下方的黑色終端機面板中，輸入以下指令並按 Enter： 
    npx @deepseek-ai/dsh web
  3. 若系統提示 Need to install the following packages...，請打 y 並按 Enter。
  4. 當終端機顯示出 http://127.0.0.1:3080 時，表示本地背景服務成功啟動（請保持這個終端機視窗開啟，不要關閉）。

步驟 3：進入 Web UI 介面並配置

  1. 打開瀏覽器（Chrome 或 Safari），網址列輸入：http://127.0.0.1:3080。
  2. 填入 API Key：點選介面中的 Settings ➔ Models，將 sk- 開頭的金鑰貼入並儲存。
  3. 選擇工作區：點擊 Choose Workspace，指定你在 VS Code 中開啟的那個網站資料夾。

步驟 4：開始對話與檢視成果

  1. 在網頁介面的輸入框用廣東話或中文下達指令：
    💬 「幫我在 index.html 頂部新增一個導覽列，並將 style.css 中的按鈕設置為圓角樣式。」
  2. 送出後，AI 會自動處理檔案。
  3. 處理完成後切換回 VS Code，左側檔案與程式碼已自動寫入並更新！

💡 第五章：進階提問公式與 4 大高效開發策略

5.1 最佳提問公式（Prompt Formula）

下指令時遵循：「背景 + 目標 + 限制」，產出結果最精準。

  • ❌ 反面範例：「幫我改好這個網站。」（太模糊，AI 容易自由發揮改壞東西）
  • ✅ 正面範例：
    「【背景】這是一個履歷網站。
    【目標】請在頁面底部新增一個 Contact Form 表單，包含 Name、Email 與 Message 輸入框。
    【限制】請只修改 index.html 與 style.css，不要改動 assets/ 資料夾內的任何圖片檔案。」

5.2 四大開發策略

  1. 增量開發 (Incremental Development)：切勿一次給予過龐大的需求。應拆解成小步快跑：先做登入框 ➔ 再做黑夜模式 ➔ 再做響應式排版。
  2. 明確指定改動檔案：若只需調整樣式，明確告知：「請只針對 assets/style.css 進行修改。」
  3. 善用版本控制備份：在進行大範圍改動前，先複製一份專案資料夾備份，或執行 git commit，方便改砸時一鍵復原。
  4. 日後開發極簡 3 步驟：
    • VS Code：開啟 Folder ➔ 執行 npx @deepseek-ai/dsh web
    • 瀏覽器：開啟 http://127.0.0.1:3080 下指令
    • VS Code：切回查看並測試改好的 Code！

❓ 第六章：常見問題與排障指南 (Troubleshooting)

遇到的問題 / 報錯 原因分析 解決方法
打不開 127.0.0.1:3080 VS Code 裡的 Terminal 服務未啟動或被關閉了。 回到 VS Code Terminal，重新執行 npx @deepseek-ai/dsh web，並確保 Terminal 視窗維持開啟。
提示 npx: command not found 電腦尚未安裝 Node.js 環境。 請前往 nodejs.org 下載並安裝 LTS 版本的 Node.js。
AI 提示 API Key 無效或欠費 Key 輸入錯誤，或 DeepSeek 帳號額度已耗盡。 檢查 Settings 中的 Key 是否複製完整；前往 DeepSeek 官網後台檢查 Usage 或小額充值。
AI 改出來的 Code 跑出 Bug 需求描述有歧義，或上下文不夠清晰。 在網頁介面複製錯誤訊息貼給 AI：「執行後出現此報錯，請修正 script.js 中的邏輯。」
