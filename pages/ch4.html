FFmpeg 常用指令與 Mac 操作全攻略

Homebrew 安裝與 PATH 設定 × 資料夾切換 × MP3 / MP4 音影片壓縮速查

一、安裝 FFmpeg 與 Mac 環境設定

1. 安裝 Homebrew

打開 Mac 終端機（Terminal），貼上並執行：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

※ 提示 Password: 時，請輸入 Mac 開機密碼（輸入時畫面上不會顯示任何符號，盲打完按 Enter 即可）。出現提示時再按 Enter 繼續。

2. 設定 PATH 環境變數（解決 command not found: brew）

安裝完成後，務必執行以下兩行指令將 Homebrew 加入 PATH，否則系統會找不到 brew：

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

3. 安裝 FFmpeg

brew install ffmpeg

4. 檢查是否安裝成功

ffmpeg -version

二、Terminal 基礎操作與資料夾切換

1. 常用資料夾切換指令

用途 指令
進入「文件」資料夾 (Documents) cd ~/Documents
進入「下載」資料夾 (Downloads) cd ~/Downloads
進入「桌面」 (Desktop) cd ~/Desktop
列出目前資料夾的所有檔案 ls

2. 實戰操作範例（針對含有空格的檔名）

若你的檔案位於「文件」資料夾，名稱為 我的影片 3.m4a，請照以下步驟操作：

# 1. 進入文件資料夾
cd ~/Documents

# 2. 確認檔案是否存在
ls "我的影片 3.m4a"

ffmpeg -i "我的影片 3.m4a" -c:a libmp3lame -b:a 128k "我的影片 3.mp3"
常見錯誤提醒：
  • 拼字錯誤：請使用 brew 而非 rew。
  • 空格處理：檔名有空格時（如 我的影片 3.m4a），一定要用雙引號 " " 包起來。

用途 指令
標準壓縮 128k ffmpeg -i 輸入.mp3 -c:a libmp3lame -b:a 128k 輸出.mp3

語音用 64k ffmpeg -i 輸入.mp3 -c:a libmp3lame -b:a 64k 輸出.mp3
VBR 動態碼率壓縮（推薦） ffmpeg -i 輸入.mp3 -c:a libmp3lame -q:a 4 輸出.mp3
轉單聲道 + 壓縮 ffmpeg -i 輸入.mp3 -c:a libmp3lame -b:a 64k -ac 1 輸出.mp3
從影片抽出 MP3 ffmpeg -i 輸入.mp4 -vn -c:a libmp3lame -b:a 128k 輸出.mp3

YouTube 用（品質較好） ffmpeg -i 輸入.mp4 -c:v libx264 -crf 20 -preset medium -c:a aac -b:a 192k -movflags +faststart 輸出.mp4
